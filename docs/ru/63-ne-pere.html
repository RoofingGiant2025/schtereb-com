Не пере...

перевод · оригинал: українська

Будь для меня музою, Что звучит словно музыка Ласковыми нежными Нотами смежными.

Будь для меня цветком, Что есть весною вечною; Пьянящим душистым ароматом, Будь для меня праздником.

Будь для меня игрою, Что увлекает собою, Бурли эмоциональным потоком, Только не будь шоком.

Будь для меня нянькою, Игрушкою и забавою, Почитай мне журнал „Малятко”, Ведь я ещё дитятко.

Будь для меня милою, Улыбкою искреннею, Но прежде всего со мною Будь всегда собою.

Будь для мене музою, Що звучить мов музика Лагідними ніжними Нотами суміжними.

Будь для мене квіткою, Що є весною вічною; П’янким духмяним ароматом, Будь для мене святом.

Будь для мене грою, Що захоплює собою, Вируй емоційним потоком, Тільки не будь шоком.

Будь для мене нянькою, Іграшкою і забавкою, Почитай мені журнал „Малятко”, Бо я ще дитятко.

Будь для мене милою, Усмішкою щирою, Та перш за все зі мною Будь завжди собою.
